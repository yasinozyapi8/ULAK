# ULAK v0.1.2

Android TV odaklı IPTV/medya oynatıcı prototipi.

## Bu sürüm
- M3U/M3U8 URL desteği
- Xtream Codes giriş ekranı
- Xtream hesap doğrulama (`player_api.php`)
- Canlı kategori ve kanal çekme
- Xtream canlı stream URL üretimi (m3u8/ts)
- Kategori/kanal tarayıcısı
- Media3 / ExoPlayer tam ekran oynatma
- HTTP sunucular için cleartext desteği

Yalnızca erişim hakkınız bulunan yayın kaynaklarıyla kullanın.
