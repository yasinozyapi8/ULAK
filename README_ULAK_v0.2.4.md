# ULAK v0.2.4

TV UX ve güncelleme ekranı iyileştirmeleri.

- Güncelleme ekranında APK paket adı ve GitHub kaynak satırı gizlendi.
- Güncelleme akışı kullanıcıya sade biçimde “kontrol / indiriliyor / kuruluma hazır” durumlarını gösterir.
- Android güvenlik modeli nedeniyle sistem kurulum onayı otomatik geçilemez; bir kez bilinmeyen kaynak izni verildikten sonra yalnızca Android TV kurulum onayı gerekir.
- Ana ekran ve işlem butonlarında TV odağı artık sarı + beyaz çerçeve ile belirgin şekilde parlar.
- Xtream giriş alanlarında yazı ve etiket kontrastı artırıldı; alt butonların 720p TV ekranlarında görünmesi için yerleşim sıkılaştırıldı.
- Oynatıcıdan BACK ile kanal listesine dönüldüğünde son kategori, kanal ve liste konumu korunur.
- v0.2.3 Akıllı Oynatıcı v2 davranışı korunur.
