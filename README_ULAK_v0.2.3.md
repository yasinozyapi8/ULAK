# ULAK v0.2.3 — Akıllı Oynatıcı v2 + Güncelleme Ekranı

## Akıllı oynatıcı
- Video var fakat ses track’i 4.5 saniye içinde oluşmazsa LibVLC otomatik denenir.
- Ses var / görüntü yok ve HEVC ilk kare sorunlarında mevcut otomatik VLC fallback korunur.
- VLC de başarısız olursa sıradaki Xtream yayın adayı denenir.

## OTA / Güncelleme ekranı
- Ekran açılınca güncelleme otomatik kontrol edilir.
- Güncel / yeni sürüm / hata durumları daha net gösterilir.
- İndirme yüzdesi için yatay ilerleme çubuğu eklendi.
- APK indirildi ve kurulum izni durumları daha anlaşılır hale getirildi.
- Teknik GitHub URL metni sadeleştirildi.
