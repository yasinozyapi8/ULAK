# ULAK v0.3.5.2 — RAW oynatıcı görünüm eşitleme

- RAW kanallarda çalışan LibVLC ses/görüntü motoru korunur.
- Eski ayrı RAW alt bilgi kartı kaldırıldı.
- RAW oynatıcı alt bilgi kartı normal ULAK oynatıcısıyla aynı ölçü, tipografi, renk, logo alanı ve bilgi hiyerarşisine getirildi.
- Logo URL'si varsa gerçek kanal logosu gösterilir; yüklenemezse kanal baş harfleri kullanılır.
- Ana kartta motor/RAW teşhis metinleri gösterilmez; yalnızca kanal adı, canlı/stabil/yayın türü ve kategori bulunur.
- OK ile normal oynatıcıdaki gibi ayrı Teknik Bilgiler paneli açılıp kapanır.
- LibVLC motoru ve MPEG Audio çözümü değiştirilmedi.
